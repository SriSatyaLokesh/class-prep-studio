# Class Prep Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Class Prep Studio described in the PRD — a `/prep-class` orchestrator skill, 11 subagents in two harnesses, a `/setup-studio` installer skill, helper scripts and a structure checker — and stop with a committed, tagged build ready for a human-driven Gate 1 test run.

**Architecture:** Everything is files. The orchestrator is a skill (`.claude/skills/prep-class/SKILL.md`) that runs in the main session and starts subagents defined in `.claude/agents/` (Claude Code) and `.agents/agents/` (Antigravity, generated). Third-party skills are declared in `skill-sources.json` and installed by following `/setup-studio`. Python scripts do PDF text extraction, sample inputs, copy detection, agent-file sync and the acceptance check.

**Tech Stack:** Python 3.11+ (stdlib, `pdfplumber`, `pypdf`, `reportlab`, `markitdown[pptx]`), Node.js 20+ (`pptxgenjs`), Markdown agent/skill files, Git.

**Spec:** `docs/PREP_CLASS_PRD.md` (as amended by Task 0). Read it in full before starting; section numbers below refer to it.

## Global Constraints

- **No AI attribution anywhere.** No `Co-authored-by: Claude` trailer, no "Generated with" line, no robot emoji — in commits, files, PRs. Put this sentence in every subagent dispatch prompt, next to the commit-identity instruction.
- Commits: Conventional Commits, authored as the repo's configured git identity.
- Build branch `build/studio`; never commit build work to `main`.
- Use only tool names, paths, frontmatter fields and formats written in the PRD (§0.6).
- `scripts/check_studio.py`, `scripts/sync_agents.py`, `scripts/check_copy.py`: Python stdlib only (check_copy may import `pdf_text` and `markitdown` lazily for .pdf/.pptx inputs). No YAML dependency.
- Python 3.11+, Node 20+, `pptxgenjs` `^3`.
- Any OS: no shell-specific syntax in scripts; use `pathlib`, `subprocess.run([...])` with list args.
- 11 agent names, exactly: `textbook-researcher`, `web-researcher`, `syllabus-researcher`, `student`, `expert`, `planner`, `slides-builder`, `qna-builder`, `quiz-builder`, `notes-builder`, `reviewer`.
- Do not install mattpocock's `grill-me` skill (§10.1.3).
- Never commit installed skills or input PDFs.

## Review Focus

1. **Scanned PDF with no text layer** — `pdf_text.py` must exit with code 2 and print `no text layer in <pdf>` instead of printing empty pages that researchers would then "summarise". Test in Task 4.
2. **Ligatures and line-break hyphenation in textbook text** (`ﬁ`, `connec-\ntion`) — `check_copy.py` must normalise (NFKC, join hyphenated line breaks) so copied text still matches. Test in Task 4.
3. **Plan Flow table with a non-integer minutes cell** (`5–7`, `~10`) — `plan_minutes` must raise `ValueError` naming the cell; `check_studio.py --run` reports it as a failure line, not a traceback. Test in Task 1.
4. **Windows with only the `py` launcher** — `/setup-studio` runtime check tries `python`, then `python3`, then `py`, and uses whichever answers for all later commands; the settings allowlist covers `py`. Checked by reading in Task 3 and Task 2.
5. **Resume with a different topic in `status.md`** — orchestrator treats it as "no previous run for this topic" and asks *Resume … or start over?* only for the same topic; a different topic forces archive-then-start (nothing deleted). Checked by reading in Task 7.
